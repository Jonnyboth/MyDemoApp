AutomationFrontend · POM de 3 capas

Una arquitectura, dos motores de prueba

AutomationFrontend/ corre dos suites en paralelo — Katalon/Groovy para móvil y Playwright/Node.js para web — y ambas respetan el mismo contrato de 3 capas: Test/Script → Steps → Page → Locators. El foco activo del proyecto es Android/Katalon, así que seguimos ese lado paso a paso, del comando en la terminal hasta el reporte final.

El flujo de un test real, paso a paso
